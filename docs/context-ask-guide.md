# 실행 에이전트가 회사 문서를 묻는 방법

실행 에이전트는 회사가 등록해 확정한 정책·절차·조건 같은 문서를 직접 찾아 읽지 않고, `vacatio-os context ask --question="문서에서 찾을 사실 하나"` 명령으로 짧은 사실 하나를 질문해 답을 받는다. 서버는 회사의 공개 확정 문서 안에서만 후보를 골라 답하며, 응답에는 문서가 답한 사실(`claims`)과 그 근거 원문 구간(`evidence`), 문서에 없어 확인하지 못한 사실(`gaps`)이 나뉘어 담긴다. 태스크 본문이나 코멘트가 `#DOC-<n>`으로 특정 문서를 가리키면 질문에 그 번호를 그대로 넣어 묻고, 산출물에 근거를 적을 때는 응답 evidence의 `documentNumber`로 받은 `#DOC-<n>`만 사용한다. 확인 필요(`gaps`·`insufficient`)로 온 사실은 짐작으로 채우지 않으며, 그 사실이 결과의 핵심이면 일을 멈추고 사람에게 막힘으로 넘기고, 결과의 일부에만 쓰이는 주변 사실이면 확인하지 못한 점으로 남기고 나머지 일을 계속한다.
